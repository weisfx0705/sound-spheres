概念原作者

Sound Spheres — David Sonnenschein

本網站根據陳嘉暐老師提供的課程教材，演繹 I THINK、I AM、I TOUCH、I SEE、I KNOW、I DON'T KNOW 六個聆聽層次。教材中的原圖標題為「SOUND SPHERES — A Psychospatial Model by David Sonnenschein」。本網站為課程互動改編，並非原作者官方網站或授權聲音出版品。

六個層次描述聆聽者與聲音的關係，並非固定的距離分區。「I SEE」需要看見聲源；「I KNOW」則是未看見但能辨認。網站提供想像情境，再鼓勵學習者回到真實生活觀察。

聲音來源與製作

本版本沒有載入外部音檔。所有可聽見的聲音，皆由本網站的 app.js 使用瀏覽器 Web Audio API 即時產生。素材由本專案程序合成，無取樣音樂、商用音效庫、真人語音或現場錄音。聲音只是教學與藝術示意，不代表真實地點的紀錄。

聲景／層次聲音內容來源與方法
I THINK保留安靜不播放念頭或人聲，以文字引導察覺內在。
I AM呼吸般的氣流濾波雜訊與音量包絡；不是人體呼吸錄音。
午後的郵局紙張、印章、街道車聲示意帶通濾波雜訊、短促低音與滑頻振盪器。
島嶼的午後接觸、鳥鳴、車流示意短音、滑頻正弦波與低頻噪聲。
人海之中電子節拍、低音、人群質感原創振盪器節奏與濾波雜訊；未使用歌曲或演唱會取樣。
音樂廳的微光衣料、緩慢和弦、延音正弦波與三角波疊加原創和弦；並非交響樂團錄音或真實音樂廳脈衝響應。
走進森林交替腳步、林鳥、溪流質感短噪聲、滑頻音與較高頻的持續噪聲。
I DON'T KNOW不明的遠方聲響緩慢變化音高與濾波雜訊，不預設具體聲源。

左右位置由立體聲聲像控制，層次由音量混合呈現；本作未使用實測雙耳錄音或頭部追蹤。「真實環境」模式完全關閉合成聲景，不啟用麥克風。
